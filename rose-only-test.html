FAQ

Good questions.

Is Rose replacing my phone?+

No. Rose handles website visitors first, captures details, and helps you follow up faster. You still control the call, booking, or quote.

Does this work on my existing website?+

Usually yes. Rose installs with a small widget snippet. If your site supports custom code, it should work.

What does Rose need to know?+

Your services, hours, location, service area, common questions, and the details you want collected from each lead.

Can Rose book appointments?+

The first version focuses on answering questions and capturing leads. Booking can be added if you already use a booking link or scheduling flow.
