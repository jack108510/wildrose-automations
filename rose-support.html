Get started

  1. Open the account setup link sent to your checkout email and create your password.
  2. Sign in to Rose Workground.
  3. Open Settings → Website. Confirm that the website shown is the site where you want Rose.
  4. Choose Invite Wildrose or Do it myself.

If you do not have an account setup link, email us from the address used at checkout. Do not send a password.

Install Rose on your website

Invite Wildrose

  1. In Settings → Website, choose your website platform and Invite Wildrose.
  2. Use the platform-specific access steps shown there. Grant access to edit and publish the website; never share a password.
  3. Once you have sent the platform invitation, select I sent the invite in Workground. Include the project or site name if the form asks for it.
  4. We confirm access, install the account-specific code, and test Rose. Workground shows the setup progress.
“I sent the invite” reports the invitation. It does not mean Rose has been installed or that access has been accepted. Keep the platform invitation active until we confirm setup.

Do it myself or send it to your web person

  1. Choose your website platform and Do it myself in Workground.
  2. Copy the install code shown for your account. The code is tied to your website, so use that code rather than a sample from a demo.
  3. Follow the platform instructions, save the change, and publish the public site.
  4. Open the published website and select Check connection.

If a web person manages your site, use Copy instructions for my web person in the Invite path. They can install the same account-specific code for you.

Understand your website status

Not installed

Rose code was not verified on the website attached to your account. Check that the website address is correct, the change is published, and the code is on the public homepage. Then select Check connection again.

Code detected

The account-specific code was found at the attached website. This confirms installation, but chat, voice, and lead delivery still need testing before launch.

Waiting for access

We have your report that an invitation was sent. Our team still needs to accept it and confirm it has enough access to edit and publish the site.

Different website or demo

A demo page and your real business domain are separate. Rose will only count as installed when the code is verified on the website attached to your account. Use Change website in Settings if that address is wrong.

Some builders add code only to one page. For example, a GoDaddy Websites + Marketing HTML section must be added to each page where you want Rose. Start with the homepage so the connection check can find it.

Test Rose before launch

  1. Open your public website in a private browser window and find Rose.
  2. Ask one chat question about your business and confirm the answer is accurate.
  3. Try one voice question if voice is part of your setup.
  4. Send a test lead with your own contact details. Confirm it reaches the lead delivery email shown in Settings → Business details.

If any step fails, email us with the website URL, which step failed, and what you saw. Do not include passwords, recovery codes, or private customer data.

Account access

Forgot your password?

Use Reset password on the sign-in page. The link goes to your account email and expires after use. Resetting your password signs out existing devices.

Set up two-step verification

In Workground, open Settings → Password & security. Add an authenticator app and save the recovery codes somewhere private. Each recovery code works once.

Lost your authenticator?

Use a saved recovery code at sign-in. If you have no recovery code, email us from your account email so we can review the recovery request. We will not ask you to send your password or a two-step code.

See an unfamiliar session?

Open Settings → Password & security, sign out other devices, and reset your password. Contact us if you did not make the change.

Contact support

Sign in to Workground and open Settings → Help & support to send a request linked to your account. You will get a reference number, and your recent requests will remain visible there. Wildrose follows up by email.

For a failed install, include the platform (such as Wix or GoDaddy), the page URL you checked, and any error text. Never send login passwords, two-step codes, recovery codes, or API keys.

If you cannot sign in, email invites@wildroseautomations.ca from your account email. Include your business name and website. To add details to an existing request, include its reference number.
