GoDaddy, Wix, and locked-down builders

If your website builder is confusing, that is normal.

GoDaddy and similar website builders can be inconsistent. Some versions allow custom code. Some only allow an embed block. Some are better handled with a simple hosted Rose page.

We do not expect you to figure that out. We check what your site allows and use the best available path.
